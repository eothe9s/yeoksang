曆象 v11.1 배포 순서

1. 현재 Safari/PWA의 웹사이트 데이터는 삭제하지 마세요.
2. 가능하면 현재 프로그램의 JSON 백업을 한 번 더 내려받으세요.
3. GitHub Pages 저장소에서는 예전 앱 파일을 정리한 뒤 이 ZIP의 파일을 루트에 업로드하세요.
4. Pages 배포가 끝난 뒤 曆象을 한 번 열고 설정 → 기존 데이터 복구를 확인하세요.
5. 기존 데이터가 자동으로 보이면 그대로 사용합니다.
6. 데이터가 부족하면 설정 → 기존 데이터 복구 → 백업 파일 병합에서 별도로 제공한 `YEOKSANG_PRIVATE_RECOVERY_2026-09-04.json`을 선택하세요.
7. 병합 전후 개수를 확인한 뒤 진행하세요. 현재 기록은 복구 직전 안전본으로 남습니다.
8. 정상 복구를 확인하기 전에는 Safari 웹사이트 데이터/PWA 데이터를 지우지 마세요.

주의
- 개인 복구 JSON은 GitHub 저장소에 업로드하지 마세요.
- 200시간 챌린지 기능은 요구사항에서 제외했습니다.
