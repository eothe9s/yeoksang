# 曆象 v2.0

`PROJECT 11122`와 버전 번호를 분리한 독립 버전입니다. 목표는 오직 **수능 만점**입니다.

## v2.0 화면 방향

- 11122에서 좋았던 작은 밀도, 여백, 은은한 그라데이션을 참고했습니다.
- 사이드바는 검은 레일 대신 옅은 청회색으로 바꿨습니다.
- 상단 목표 카드는 `수능 만점`이 중심이며 10/16, 10/20, 11/19 체크포인트를 함께 봅니다.
- `오늘의 실행`은 6칸 균등 표를 폐기하고 **마감 필요량 / 실제 최대 가용 / 계획 부족·초과 / 지금 할 것** 4개만 전면에 둡니다.
- 기간 평균, 완주, 남은 계획은 보조 한 줄로 내렸습니다.
- 텐미닛 시간표는 기본 폭 **420px**로 축소했습니다.
- v11.1보다 폰트·패딩·카드 높이·버튼을 한 단계 더 줄였습니다.

## 만점 엔진은 유지

- 기존 데이터 복구/병합과 안전본
- 9/2 → 10/20 → 11/19 목표 단계
- 과정별 마감일과 실제 시간표 기반 가용시간
- 체대입시, 학교 실모, 면접, 수면 경계 제약
- 시간 미정 과정을 0으로 숨기지 않는 필요량 계산
- 90분 유연 작업의 50+40분 분할, 연속 작업 보호
- 미완료 재계획, 사용자 수동 우선권, 주간 보정
- 시험 오류 최근성, 시간붕괴, 안정성, 과정 종료 판정

## 데이터 주의

기존 저장키 `p11122_v60_db`는 **데이터 호환을 위해 유지**합니다. 이것은 브랜딩과 버전 체계가 PROJECT 11122에 종속된다는 뜻이 아닙니다.

업데이트 후 데이터가 이상해 보이면 Safari 웹사이트 데이터를 지우지 말고, 설정 → 기존 데이터 복구에서 먼저 비교/병합하세요. 개인 복구 JSON은 GitHub에 올리지 마세요.
