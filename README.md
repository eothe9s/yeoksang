# 曆象 v2.4

v2.3.1의 계산·자동배치·데이터 보존 기능을 유지하면서 시험·학습 화면을 정리하고 일일 실적 기록을 보완한 버전입니다.

## GitHub에 적용

1. 현재 앱에서 최신 백업 JSON을 내려받아 보관합니다.
2. ZIP을 압축 해제합니다. 내부 폴더 없이 22개 파일이 같은 위치에 있습니다.
3. 기존 `yeoksang` 저장소 최상위에 파일을 전체 선택해 올리고 Commit 합니다. 동명 파일은 교체합니다.
4. Pages 배포가 끝나면 기존 주소를 새로고침하고 `v2.4` 표기를 확인합니다.

저장소를 삭제하거나 다른 주소로 옮길 필요가 없습니다. ZIP 안의 `app-v200-*`, `app-v210.js`, `app-v220-analysis.js`, `app-v230.js`, `app-v231.js` 등은 파일명에 옛 버전이 있어도 현재 필요한 파일입니다.

브라우저 저장 키 `p11122_v60_db`와 스키마 14를 유지합니다. Safari 웹사이트 데이터를 지우지 마세요. 개인 백업 JSON은 GitHub에 올리지 마세요. 배포본에는 개인 데이터나 덮어쓰기용 seed가 없습니다. 새 기기에서는 본인의 백업을 가져와야 합니다.

## 오늘과 일일 보고

- 오늘 마감 필요량 숫자를 검정으로 바꾸고 그 아래 미정 문구와 기간 평균 표시를 없앴습니다. 계산 데이터 자체는 유지합니다.
- 할 일의 `실적`에서 실제 시간·수량·범위·메모를 기록합니다. 계획 수량과 단위는 할 일 편집에서 입력할 수 있습니다.
- `오늘 마감`에서 실적 확인, 보고서 미리 보기, 복사를 할 수 있습니다. 복사한 보고서를 대화창에 붙여 넣으세요.
- 보고서는 과목·할 일·교재·계획 범위·실제 범위·수량·시간 차이를 포함합니다. 같은 단위의 수량과 실제 시간이 있을 때만 시간당 분량을 비교합니다. 이는 분량 비교이며 학습 효과나 정답률 판정은 아닙니다.
- 할 일을 줄이거나 이월해도 처음 포착한 그날의 계획과 실적이 남습니다. 미래 계획은 미리 고정하지 않습니다.
- 완료 체크만으로 실제 시간·수량을 만들어 넣지 않습니다. 시간표로 추정한 하루 순공과 직접 입력한 실적 합계도 구분합니다.
- 실적을 일부 완료로 바꾸는 것만으로 이미 완료한 강의·책 세부 진도를 지우지 않습니다. 세부 진도는 기존 완료 체크에서 조정합니다.

업데이트 전에 이미 수정·이월되어 사라진 원래 계획은 복원할 수 없습니다. 비교 기준은 v2.4가 처음 포착한 계획입니다. 기존 기록을 소급하여 정확한 실제 시간으로 바꾸지 않습니다.

## 학습과 휴지통

- 중복되던 과정별 총량 위험 목록을 제거하고 과정 카드의 수정으로 통합했습니다.
- 기본 카드에 이름·진도·마감·남은 시간·오늘 필요량·수정·삭제를 남겼습니다. 직접 입력, 검증 대기, 수강·복습·적용·시간 내 재현 등의 반복 표시를 제거했습니다. 기존 세부 판단 데이터는 유지합니다.
- 과정 삭제 시 현재 과정 목록과 과정 필요량 계산에서 제외합니다. 휴지통에서 복원할 수 있으며 과거 할 일과 강의·책의 완료 기록은 보존합니다.
- 휴지통에 개별 영구 삭제와 전체 비우기를 추가했습니다. 확인 후 실행하며 다른 활성 기록을 함께 삭제하지 않습니다. 오래된 항목을 자동 삭제하지 않습니다.
- 삭제한 과정을 휴지통에서 영구 삭제하면 앱에서 복원할 수 없습니다. 과거 기록의 참조와 삭제 상태 유지를 위한 내부 정보는 남습니다.

## 시험

- 시험 기록 / 성적 흐름 / 실전·규칙 탭으로 나눴습니다. 목록은 10개씩 표시하고 검색·필터·페이지 이동·상세 보기를 제공합니다.
- 직접 기록과 오답 파일로 가져온 시험을 한 목록에 표시합니다. 가져온 기록에는 오답파일 분석 표시가 남습니다.
- 가져온 과거 시험은 기본 해결 완료이며 현재 미해결·재풀이·우선순위에 자동 반영하지 않습니다. 다시 풀기로 선택한 문항만 대기에 들어갑니다. 원래 오답과 분석 내용은 보존합니다.
- 제목의 응시 날짜를 아래 세부 정보로 옮겼습니다. 응시일이 있는 시험은 최신순, 없는 시험은 그 뒤에서 시험 연도·회차순입니다. 없는 응시일은 만들지 않습니다.
- 새 시험 구분은 평가원 모의평가·교육청 학력평가·수능·사설 모의고사 네 가지입니다. 예전 구분의 기록도 전체 보기에서 찾을 수 있습니다. 시험명으로 출처가 분명한 경우에만 분류를 보완합니다.
- 시험 입력에서 중복 유형·범위, 종료 시 남은 시간, 처음 막힌 문항, 마지막 정상 풀이 문항, 공통 원인, 시간 붕괴 메모를 제거했습니다. 기존 해당 값은 수정·저장 시 보존합니다.
- 전체 과목 시험도 하나의 기록으로 입력·수정합니다. 원점수 0과 미입력을 구분합니다.
- 원점수와 등급을 한 그래프에 표시합니다. 왼쪽은 점수, 오른쪽은 등급이며 1등급이 위쪽입니다. 파란 실선·분홍 점선과 서로 다른 표식을 사용합니다. 점을 누르면 시험과 값을 확인합니다.
- 미입력은 0으로 연결하지 않습니다. 응시일 기준과 연도·회차 기준, 시험 범위가 다른 기록 사이에는 선을 끊습니다. 범위 미정 시험은 독립된 점으로 표시합니다.
- 표시한 회색 설명 문구와 등급 나열을 제거했습니다. 반복 문항 기록이 부족할 때 세로로 길게 늘어나던 빈 화면도 고쳤습니다.

## 유지한 제한

수면·고정 일정·연속 풀이·실제 가용시간·마지막 10일 제약과 사용자 우선순위를 유지합니다. 마감 지난 잔량을 오늘 필요량에 전부 더하거나 미완료를 다음 날 몰아넣지 않습니다. 시간 근거가 없는 과정은 계산상 미정으로 유지합니다.
