## 이번 수정: 기존 디자인 복원

v2.5에서 추가한 전역 글자 확대·진한 색상·버튼 최소 크기·완료 항목 불투명도 변경을 제거했습니다. 글씨, 버튼, 선택 탭, 시간표 교시, 등급 색, 하단 표시는 다시 v2.4 스타일을 따릅니다.

저장·복구·완주율·대기함·자동배치 계산은 v2.5와 동일합니다. 새 기록으로 초기화하거나 DB를 교체하지 않습니다. 숨김 속성 처리, 좁은 화면의 가로 넘침 방지, 모달 포커스·편집 취소 확인, 접히는 목록과 저장 공간 관리도 유지합니다. 기존 v2.5와 원본 v2.4 ZIP은 별도로 보존했습니다.

v2.4의 기능을 유지하면서 저장·대기함·완주율·계산·화면을 안정화한 버전입니다. 원본 DB를 새 데이터로 교체하지 않습니다.

## 먼저 알아둘 변경

| 동작 | 원래 날짜 | 대기함 / 다음 날짜 | 완주율 |
|---|---|---|---|
| 삭제 | 목록에서 제거 | 자동 추가하지 않음 | 그날 분모에서도 제외 |
| 대기함 | 미완료로 유지 | 한 번만 추가 | 원래 날짜의 미완료 유지 |
| 같은 날로 복귀 | 원래 항목 재사용 | 대기함에서 빠짐 | 중복 집계 없음 |
| 다음 날로 배정 후 완료 | 원래 날짜 미완료 유지 | 다음 날 항목만 완료 | 전날을 소급 완료하지 않음 |

삭제는 휴지통에서 복원할 수 있습니다. 대기함은 같은 일을 매번 복제하지 않습니다. 강의를 여러 개 묶은 할 일은 기존의 강의 단위 집계를 유지합니다. 이전 버전에서 이미 사라진 원래 날짜 항목을 임의로 새로 만들지는 않습니다.

## 저장 공간 오류가 있었을 때

새 전체 DB 사본의 자동 생성을 중지했습니다. 기존 사본은 자동 삭제하지 않으므로 업데이트만으로 빈 공간이 바로 생기지는 않습니다.

1. 설정 또는 기록 보호 화면에서 **안전본 내보내기**를 누릅니다. 현재 원본과 미저장 변경도 해당 파일에 포함됩니다.
2. 실제 내려받은 JSON을 **받은 파일 확인**에서 선택합니다. 현재 브라우저 사본과 내용이 일치해야 삭제 선택이 열립니다.
3. 보관한 안전본만 선택하여 **선택 안전본 삭제**를 누릅니다. 현재 공부 DB는 이 삭제 대상이 아닙니다.
4. 저장 실패 화면이라면 **공간 정리 후 저장 재시도**를 누릅니다. 실패 순간의 변경을 저장합니다.
5. 계속 실패하면 원본과 미저장 변경을 각각 내보내 보관합니다. Safari 웹사이트 데이터를 지우지 마세요.

되돌리기 사본을 정리한 뒤에는 그 사본이 담긴 외부 파일이 복구 자료입니다. 안전본 묶음 JSON은 일반 앱 백업과 형식이 다르므로, 새 기기용으로는 별도로 **전체 기록 내보내기**도 보관하세요. 자동 내부 사본은 외부 백업을 대신하지 않습니다.

## v2.5 안정화

- 대기함 왕복과 오늘 마감은 중간 상태를 따로 저장하지 않습니다. 저장 실패 시 성공 안내를 내지 않고, 실패한 변경을 별도 내보내기할 수 있습니다.
- 같은 주소의 새 버전 탭은 한 탭만 쓰기 가능하게 제한합니다. 다른 탭에서 기록이 바뀌면 덮어쓰지 않습니다. 편집할 탭 하나만 남기고 새로고침하세요.
- 백업 병합은 시험·분석 패키지 ID를 구분합니다. 삭제한 할 일의 자동 부활을 막고, 충돌에서 직접 복원할 수 있습니다.
- 마지막 분석 가져오기 되돌리기는 해당 분석 묶음만 제거합니다. 그 뒤에 새로 한 공부 기록을 통째로 되돌리지 않습니다.
- 겹친 시간표 구간을 이중 집계하지 않습니다. 직접 확정한 하루 시간, 입력한 할 일 실적, 시간표 추정을 구분합니다. 일부 할 일만 시간을 입력했다면 입력된 실적 합계이지 하루 전체를 측정한 값은 아닙니다.
- 잘못된 문항 번호를 조용히 바꾸지 않고 입력 단계에서 확인합니다. 0점과 미입력은 다르게 처리합니다.
- 가져온 시험을 삭제하면 그 시험에서 다시 활성화한 미해결·미완료 재풀이도 연결해서 정리하고, 휴지통 복원 시 함께 복원합니다. 이미 완료한 공부 기록은 지우지 않습니다.
- 자동 이월 추천은 작업 길이·연속성·시간표·수면 경계를 확인합니다. 맞는 날이 없거나 시간이 미정이면 대기함을 추천합니다. 사용자가 직접 선택한 이월은 별도입니다.
- 반복 가용시간 계산을 한 화면 갱신 안에서 재사용합니다. 학습 세부 목록과 설정의 긴 복구 목록을 접어두며, 기능·기록은 그대로입니다.
- 휴대폰·iPad 분할 화면의 가로 넘침, 모달 포커스·편집 취소 확인, 복사 실패 안내를 보완했습니다. 글씨·버튼을 키우고 진하게 만들었던 변경은 v2.5.1에서 철회했습니다.
- 업데이트 파일이 모두 받아지기 전에는 새 버전을 활성화하지 않습니다. 앱 하단에는 실제 확인한 오프라인 버전을 표시합니다.

## 오늘과 일일 보고

- 오늘 마감 필요량 숫자를 검정으로 바꾸고 그 아래 미정 문구와 기간 평균 표시를 없앴습니다. 계산 데이터 자체는 유지합니다.
- 할 일의 `실적`에서 실제 시간·수량·범위·메모를 기록합니다. 계획 수량과 단위는 할 일 편집에서 입력할 수 있습니다.
- `오늘 마감`에서 실적 확인, 보고서 미리 보기, 복사를 할 수 있습니다. 복사한 보고서를 대화창에 붙여 넣으세요.
- 보고서는 과목·할 일·교재·계획 범위·실제 범위·수량·시간 차이를 포함합니다. 같은 단위의 수량과 실제 시간이 있을 때만 시간당 분량을 비교합니다. 이는 분량 비교이며 학습 효과나 정답률 판정은 아닙니다.
- 할 일을 줄이거나 이월해도 처음 포착한 그날의 계획과 실적이 남습니다. 미래 계획은 미리 고정하지 않습니다.
- 완료 체크만으로 실제 시간·수량을 만들어 넣지 않습니다. 시간표로 추정한 하루 순공과 직접 입력한 실적 합계도 구분합니다.
- 실적을 일부 완료로 바꾸는 것만으로 이미 완료한 강의·책 세부 진도를 지우지 않습니다. 세부 진도는 기존 완료 체크에서 조정합니다.

업데이트 전에 이미 수정·이월되어 사라진 원래 계획은 복원할 수 없습니다. 비교 기준은 v2.4가 처음 포착한 계획입니다. 기존 기록을 소급하여 정확한 실제 시간으로 바꾸지 않습니다.

- 중복되던 과정별 총량 위험 목록을 제거하고 과정 카드의 수정으로 통합했습니다.
- 기본 카드에 이름·진도·마감·남은 시간·오늘 필요량·수정·삭제를 남겼습니다. 직접 입력, 검증 대기, 수강·복습·적용·시간 내 재현 등의 반복 표시를 제거했습니다. 기존 세부 판단 데이터는 유지합니다.
- 과정 삭제 시 현재 과정 목록과 과정 필요량 계산에서 제외합니다. 휴지통에서 복원할 수 있으며 과거 할 일과 강의·책의 완료 기록은 보존합니다.
- 휴지통에 개별 영구 삭제와 전체 비우기를 추가했습니다. 확인 후 실행하며 다른 활성 기록을 함께 삭제하지 않습니다. 오래된 항목을 자동 삭제하지 않습니다.
- 삭제한 과정을 휴지통에서 영구 삭제하면 앱에서 복원할 수 없습니다. 과거 기록의 참조와 삭제 상태 유지를 위한 내부 정보는 남습니다.

## 시험

- 시험 기록 / 성적 흐름 / 실전·규칙 탭으로 나눴습니다. 목록은 10개씩 표시하고 검색·필터·페이지 이동·상세 보기를 제공합니다.
- 직접 기록과 오답 파일로 가져온 시험을 한 목록에 표시합니다. 가져온 기록에는 오답파일 분석 표시가 남습니다.
- 가져온 과거 시험은 기본 해결 완료이며 현재 미해결·재풀이·우선순위에 자동 반영하지 않습니다. 다시 풀기로 선택한 문항만 대기에 들어갑니다. 원래 오답과 분석 내용은 보존합니다.
- 제목의 응시 날짜를 아래 세부 정보로 옮겼습니다. 응시일이 있는 시험은 최신순, 없는 시험은 그 뒤에서 시험 연도·회차순입니다. 없는 응시일은 만들지 않습니다.
- 새 시험 구분은 평가원 모의평가·교육청 학력평가·수능·사설 모의고사 네 가지입니다. 예전 구분의 기록도 전체 보기에서 찾을 수 있습니다. 시험명으로 출처가 분명한 경우에만 분류를 보완합니다.
- 시험 입력에서 중복 유형·범위, 종료 시 남은 시간, 처음 막힌 문항, 마지막 정상 풀이 문항, 공통 원인, 시간 붕괴 메모를 제거했습니다. 기존 해당 값은 수정·저장 시 보존합니다.
- 전체 과목 시험도 하나의 기록으로 입력·수정합니다. 원점수 0과 미입력을 구분합니다.
- 원점수와 등급을 한 그래프에 표시합니다. 왼쪽은 점수, 오른쪽은 등급이며 1등급이 위쪽입니다. 파란 실선·분홍 점선과 서로 다른 표식을 사용합니다. 점을 누르면 시험과 값을 확인합니다.
- 미입력은 0으로 연결하지 않습니다. 응시일 기준과 연도·회차 기준, 시험 범위가 다른 기록 사이에는 선을 끊습니다. 범위 미정 시험은 독립된 점으로 표시합니다.
- 표시한 회색 설명 문구와 등급 나열을 제거했습니다. 반복 문항 기록이 부족할 때 세로로 길게 늘어나던 빈 화면도 고쳤습니다.
