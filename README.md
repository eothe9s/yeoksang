## 저장과 복구

주기록은 IndexedDB의 한 레코드에 보관하고 저장을 순서대로 처리합니다. 기존 localStorage 원본은 보존하지만 이후 변경은 새 저장소에 기록합니다. 따라서 앞으로의 최신 기록은 앱 내 백업 또는 `recovery.html`에서 내보내세요. 구 localStorage 원본은 과거 상태입니다.

저장 실패 때는 원본과 미저장 변경을 각각 내보낸 뒤 복구 화면의 재시도를 사용합니다. 되돌리기 한도를 넘어간 이전 변경은 최근 변경 목록에서 사라지므로 중요한 기록은 별도 백업을 유지합니다. 브라우저 자체 데이터 삭제·기기 고장까지 막는 서버 백업은 아닙니다.

기존 안전본은 자동 삭제하지 않습니다. 화면의 안전본 관리에서 내보낸 파일을 확인한 뒤 선택한 사본만 정리할 수 있습니다. 삭제된 과정·시험의 휴지통과 최근 변경 목록은 서로 다릅니다.
