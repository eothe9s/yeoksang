# 曆象 v2.3

수능 만점 운영체제 曆象의 9주 운영 정리 버전입니다.

## 핵심 변화
- 가져온 과거 오답 시험을 성적 흐름과 등급 흐름에 포함합니다.
- 과거 오답은 현재 미해결 문항, 오늘 우선순위, 재풀이 대기에 자동 반영하지 않습니다.
- 과거 시험 1회 / 문항 1개 / 가져온 분석 패키지 전체를 휴지통으로 이동하고 복원할 수 있습니다.
- 오늘 계획이 아직 없으면 `부족` 대신 `아직 계획 안 됨`으로 표시합니다.
- 오늘 화면에 이번 7일의 필요시간 범위와 실제 최대 가용시간을 함께 표시합니다.
- `재가동 3일`은 공부량을 새로 만들어내지 않고, 비어 있는 과목을 다시 계획에 올리도록 판단 문구를 바꿉니다.
- 학습 화면에서 과정별 `지연 / 마감 불가 / 상한 위험`을 보여줍니다.
- 현재 시험의 미해결·재발 오류가 계획된 공부 안에서 무엇을 확인할지와 연결됩니다.
- 11/9~11/18은 새 진도 자동배치를 막는 마지막 10일 보호 구간입니다.
- Today 화면의 `확정`, `불가침 규칙`, `진도를 위해 수면을 보상하지 않습니다.` 문구를 제거했습니다.

## 오답 분석 파일
오답 분석 패키지는 `reviewStatus: final`인 완성본만 가져옵니다. 과거 시험은 정확한 날짜를 억지로 만들지 않고 학년도·회차 순서로 성적 흐름에 배치합니다.

개인 분석 JSON이나 개인 백업 JSON은 공개 GitHub 저장소에 올리지 마세요.
