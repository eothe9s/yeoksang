# 曆象 · PROJECT 11122 v10.1

수능 당일의 실력과 안정성을 최대화하기 위한 개인 학습 운영체제입니다. 기록을 쌓는 데서 끝나지 않고, 현재 진도·남은 기간·실제 시간표·시험 오류를 연결해 다음 행동을 다시 계산하는 폐쇄루프를 목표로 합니다.

## 핵심 흐름

목표 → 남은 분량/기간 → 실제 가용시간 → 오늘 최소 필요량 → 시간표 배치 → 실행 → 미완료 처리 → 시험/오답 분석 → 반복 오류 탐지 → 처방 → 처방 효과 확인 → 다음 날·다음 주 재계획

## v10.1에서 닫은 핵심 문제

- 목표 단계: 9/2 모평 → 10/20 학평 → 11/19 수능을 실제 판단 로직에 반영
- 1차 학습 폐쇄: 과정별 목표일을 사용하며 기본 폐쇄일은 10/16
- 실제 가용시간: 고정 10h/14h가 아니라 해당 날짜 시간표의 자습 블록을 기준으로 계산
- 고정 제약: 월·수·토 체대입시학원, 토요일 학교 실모, 10/7~8 공군사관학교 면접
- 수면 우선: 평일 23:00 전 취침 / 06:30 전 기상, 주말 기상 목표는 비워 둠. 수면 경계를 넘어 자습을 자동 배치하지 않음
- 과정 시간: 근거가 없는 과정은 0분으로 숨기지 않고 `미정`으로 분리. 범위만 아는 과정은 범위 계산
- 공개 전 강좌: 공개 시작일 전에는 오늘 필요량에 억지로 포함하지 않음
- 자동배치: 긴 할 일을 여러 자습 블록에 나눠 배치
- 미완료 처리: 중요도와 부하에 따라 다음 날/분산/대기/제거를 구분
- 사용자 우선권: 수동 과목 우선순위를 자동 판단보다 위에 둘 수 있음
- 주간 보정: 핵심 우선순위와 중단 자료가 다음 주 판단에 실제 영향
- 시험 폐쇄루프: 과목별 미풀이 번호, 첫 막힘, 마지막 정상 풀이, 남은 시간, 오류 패턴, 재풀이 상태를 연결
- 오류 가중치: 최근·미해결 오류를 더 무겁게 반영
- 과정 종료: 완강과 종료를 분리하고 후속 실전 증거를 함께 봄
- 데이터 안전: 마이그레이션 전 백업, 개인 기준값 적용 전 백업, import 전 백업, 일일 안전 스냅샷, 복원 UI
- iPad 가독성: 확대 금지 제거, 일반 UI 글자 크기 상향, 모바일 입력 16px, 주요 터치 영역 44px 이상
- 비타민/등산/무등산 등 수능 운영과 무관한 잔재 제거

## 현재 개인 기준값

새 설치에는 전체 생활기록이 아니라 현재 공부 운영에 필요한 최소 기준값만 포함됩니다. 2026-09-02 모평 점수/오답과 확인된 현재 진도, 과정별 시간 근거, 과목별 시험 규칙이 포함됩니다. 등급이나 소요시간처럼 원자료에 없던 값은 만들지 않았습니다.

2026-09-07 기준 계산에서 시간 근거가 확인된 남은 학습량은 약 303.3~416.8시간이며, 당일 확정 필요량은 약 4.7~6.5시간입니다. 다음 세 항목은 시간 근거가 없어 의도적으로 미정으로 남아 있습니다.

- 수Ⅰ·수Ⅱ 4점 문제 모음
- 미적분 1등급 마스터급 4점
- 영어 방과후

미정 항목은 숫자에서 조용히 제외되지 않고 부분계산 경고로 표시됩니다.
