# 曆象 v2.3.1

v2.3의 기능과 화면 구성을 유지한 계산·기록 보존 수정판입니다.

## 달라진 점

- 마감이 지난 과정은 오늘에 전부 몰아넣지 않습니다. 오늘·기간 평균·주간 배정 필요량과 분리해 `재마감 필요` 잔량으로 계속 표시합니다. 기존 마감일은 사용자가 조정할 때만 바뀝니다.
- 같은 기간에 끝내야 하는 과정들이 실제 가용시간을 함께 사용하도록 판정합니다. 8시간에 6시간짜리 과정 두 개가 있으면 기간 총량 초과로 표시합니다. 주간 필요량도 날짜 수 대신 해당 기간의 실제 가용시간 비중으로 계산합니다.
- 재발로 기록한 문항과, 확인 통과 후 다시 미해결로 돌아온 문항을 재발 집계에 포함합니다. 과거 분석 아카이브는 현재 재풀이·우선순위에 자동 편입하지 않습니다.
- 재가동 모드는 이미 입력한 할 일의 핵심 과제와 완료 기록을 사용합니다. 할 일을 자동으로 늘리지 않으며 사용자가 지정한 과목 우선순위를 유지합니다.
- 최초 화면을 표시하면서 기존 시간표를 덮어쓰지 않습니다. 고정일정 변경으로 사라지는 블록에 완료·실제시간·할 일 배정 기록이 있으면 보존합니다. 휴지통도 날짜 경과만으로 자동 삭제하지 않습니다.

## GitHub에 적용

1. 사용 중인 앱에서 최신 백업 JSON을 내려받아 보관합니다.
2. 이 ZIP을 압축 해제합니다. 내부 폴더는 없으며 파일이 모두 같은 위치에 있습니다.
3. 기존 `yeoksang` 저장소 최상위에 파일을 전체 선택해 올리고 Commit 합니다. 기존 동명 파일은 새 파일로 교체합니다.
4. GitHub Pages 배포가 끝나면 기존 앱 주소를 새로고침합니다. 왼쪽 버전 표기가 `v2.3.1`인지 확인합니다.

새 저장소나 다른 주소로 옮길 필요가 없습니다. Safari 웹사이트 데이터는 지우지 마세요. 개인 백업 JSON은 GitHub 저장소에 올리지 마세요. 이 배포본에는 개인 백업을 넣지 않았습니다. 기존 브라우저 저장 키와 데이터 스키마 14를 유지합니다.

## 계산의 범위

시간 미정·재마감 전 잔량은 별도로 표시합니다. 따라서 알려진 과정의 총량 초과가 없다는 표시가 모든 공부를 끝낼 수 있다는 뜻은 아닙니다. 기간 총량 판정은 연속 블록, 기기 사용 제한, 과정에 연결하지 않은 별도 과제까지 배치 가능함을 보장하지 않습니다. 자동배치의 수면·고정일정·연속 풀이 제한은 유지합니다.

오늘 화면의 재마감 목록에서 `마감 조정`, 학습 화면에서 `분량·마감 조정`을 눌러 기존 편집 창을 열 수 있습니다. 남은 일을 자동 이월하거나, 입력 없이 해결된 오답으로 처리하지 않습니다.

## 검증

검증 범위와 제한은 QA_V231.md에 기록했습니다. 실제 iPad Safari에서의 표시·터치·서비스워커 갱신은 아직 확인하지 못했습니다. 배포 후 기존 할 일·시험·진도가 보이는지 확인하세요.
