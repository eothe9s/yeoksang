# 曆象 v11

수능 만점을 목표로 하는 개인 학습 운영체제입니다.

## 핵심 원칙

- 브랜드와 목표는 `曆象 · 수능 만점 운영체제`로 통일했습니다.
- 기존 데이터가 있으면 새 기준값이 과거 기록을 지우지 않습니다.
- 하루 필요시간은 하나의 숫자로 위장하지 않고 `오늘 실제 최대 가용 / 오늘 마감 필요량 / 남은 기간 평균 / 계획 부족·초과`로 분리합니다.
- 시간 근거가 없는 과정은 0시간으로 숨기지 않고 `미정`으로 남깁니다.
- 평일 수면 규칙은 23:00 전 취침, 06:30 전 기상이며 주말 기상 목표는 고정하지 않습니다.
- 자동배치는 실제 블록 분량을 사용합니다. 예: 90분 유연 작업은 50분 + 40분으로 배치하고 남은 10분은 재사용합니다. 연속 작업은 끊어진 블록에 배치하지 않습니다.
- 자동계획은 사용자 판단보다 우선하지 않습니다.

## 화면

메인 화면은 6개로 고정했습니다.

1. 오늘
2. 시간표
3. 학습
4. 시험
5. 분석
6. 설정

`할 일`, `시간 블록`, `시간 블록에 할 일 선택` 등의 편집 폼은 기본 화면 아래에 붙지 않고 버튼을 눌렀을 때만 고정 오버레이/시트로 열립니다.

## 기존 데이터 복구

설정 → **기존 데이터 복구**에서 다음을 할 수 있습니다.

- 현재 브라우저에 남아 있는 구버전 저장키 및 안전본 검색
- 현재 데이터와 복구 후보의 개수 비교
- 기존 기록을 지우지 않는 병합 복구
- 외부 JSON 백업 파일 병합

중요: **복구하기 전에 Safari의 웹사이트 데이터나 홈 화면 PWA 데이터를 삭제하지 마세요.** 과거 localStorage 안전본이 남아 있을 수 있습니다.

2026-09-04 전체 백업은 배포 ZIP에 포함하지 않았습니다. GitHub Pages 소스에 개인 기록이 공개되는 것을 막기 위한 조치입니다. 별도로 제공되는 개인 복구 JSON을 설정의 백업 파일 병합에서 선택하면 됩니다.
