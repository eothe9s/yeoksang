# 曆象 v2.2

수능 만점 운영체제 曆象의 오답 분석 자동화 업데이트입니다.

- v2.1.1 저장·부팅 안전장치 유지
- 오답 분석 JSON 증분 병합
- 과거 오답 아카이브와 현재 활성 오답 분리
- 같은 패키지 중복 가져오기 차단
- 사용자 원인 / AI 추론 provenance 분리
- 번호 미확인 문항 보존
- 가져오기 직전 백업 다운로드
- 분석용 컨텍스트 JSON 내보내기
- 기존 상세 오답 폼은 기본적으로 접고, 필요할 때만 직접 수정

개인 분석 JSON이나 개인 백업 JSON은 공개 GitHub 저장소에 올리지 마세요.

## v2.2.1
- 가져온 과거 시험도 시험 기록 화면에서 읽을 수 있습니다. 단, 현재 우선순위/미해결/재풀이 대기에는 자동 반영하지 않습니다.
- 오답 분석 패키지는 대화 검토가 끝난 `reviewStatus: final` 완성본만 가져옵니다.
- 기존 v2.2 첫 경제 패키지는 초안 취급입니다. 확인 뒤 새 완성본을 사용하세요.
