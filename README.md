# 曆象 · PROJECT 11122 v9.0

수능 만점을 위한 실행 운영체제. PROJECT 11122 v8의 실행 기능을 몸체로 유지하고, 曆象의 필요량 계산·시험 분석을 통합한 버전입니다.

## 핵심
- 오늘 → 시간표 배정 → 실행 → 마감 → 분석 → 재계획
- 텐미닛 시간표, 날짜별 시간표 유형/예외/복원, 주간 시간표, 학습 자판기, 월간 달력/분석, 지금 할 것, 할 일, 완주율/순공, 저장 시간표, 수면/컨디션 복구
- 실전 안정성, 오류 패턴, 과목별 시험 규칙 3개, 과정 종료 기준, 주간 지휘 추가
- 평일 23:00 전 취침 / 06:30 전 기상. 주말은 기상 목표를 강제하지 않음
- 자습 블록은 수면 경계 뒤로 저장할 수 없음. 진도 보충을 위해 수면을 깎는 계획 금지
- 반복 자동화는 데이터는 보존하지만 기본 비활성화
- PROJECT 11122 JSON과 曆象 JSON 복원 지원
- 개인 기록은 코드에 포함하지 않음. 기존 동일 origin의 localStorage는 DB 키를 유지해 자동 승계
